# Group Instances

- `groups_get_all_instances`: Get all group instances for a submission
- `groups_ensure_target_count`: Ensure a target group count (idempotent; organization secret key only)
- `groups_ensure_min_instances`: Ensure minimum group instances exist (idempotent)
- `groups_get_instances`: Get instances for a specific repeatable group
- `groups_add_instance`: Add a new instance of a repeatable group
- `groups_remove_instance`: Remove a group instance
