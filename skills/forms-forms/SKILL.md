# Forms

- `forms_list_forms`: List all forms for the organization
- `forms_create_form`: Create a new form definition
- `forms_get_form_by_slug`: Get form by slug
- `forms_get_form_by_type`: Get active form by type
- `forms_list_fields`: List fields for a form
- `forms_create_field`: Create a form field
- `forms_bulk_create_fields`: Bulk create form fields
- `forms_get_field`: Get a form field by ID
- `forms_update_field`: Update a form field
- `forms_delete_field`: Delete a form field
- `forms_list_groups`: List field groups for a form
- `forms_create_group`: Create a field group
- `forms_get_group`: Get a field group with its fields
- `forms_update_group`: Update a field group
- `forms_delete_group`: Delete a field group
- `forms_get_form`: Get form by ID
- `forms_update_form`: Update a form
- `forms_delete_form`: Delete a form
