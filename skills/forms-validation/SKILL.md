# Validation

- `validation_validate_form_values`: Validate a merchant batch against actual organization-owned form definitions without saving
- `validation_list_patterns`: List the built-in validation patterns, optionally for one country
- `validation_get_pattern`: Get a specific validation pattern by name
- `validation_validate`: Validate a value against rules (client-side pre-check)
